# Instagram 맞팔 확인

인스타그램에서 내보낸 팔로워·팔로잉 JSON으로 **내가 팔로우하지만 나를 팔로우하지 않는 아이디**를 찾습니다.
파일 가져오기·비교·검색·복사·TXT/CSV 저장은 로그인 없이 로컬에서 처리합니다.

> **이전 직접 목록 수집 버전에 대해 사용자 요청으로 남긴 경고**
>
> **경고: 이 프로그램을 사용하면 봇 사용으로 판정되어 인스타그램 계정이 확정적으로 정지됩니다. 사용하지 마세요.**
>
> 위 문구는 이전 방식에 대한 경고입니다. 현재 로컬 JSON 비교는 인스타그램에 접속하지 않습니다.
> 선택 기능인 로그인·자동 내보내기는 온라인 동작이며, 실제 계정 연동은 아직 검증하지 않았습니다.

## 설치와 실행

검증 환경은 macOS Apple Silicon, Python 3.9.6입니다. 검증한 직접·전이 의존성 버전을
`requirements.lock.txt`에 고정했고 `requirements.txt`가 이를 설치합니다. 다른 운영체제와 Python 조합은 별도 검증이 필요합니다.

```sh
python3 -m venv venv
venv/bin/python -m pip install -r requirements.txt
venv/bin/python setup_check.py
venv/bin/python -m uvicorn main:app --host 127.0.0.1 --port 18765
```

앱 주소는 `http://127.0.0.1:18765`입니다. 바탕화면 앱은 [DESKTOP.md](DESKTOP.md)를 참고하세요.
웹 서버는 어느 작업 폴더에서 불러와도 프로젝트의 정적 파일을 찾습니다.
명령어를 다른 폴더에서 실행할 때는 프로젝트를 `--app-dir`로 지정하세요.

```sh
/path/to/project/venv/bin/python -m uvicorn main:app --app-dir /path/to/project --host 127.0.0.1 --port 18765
```

`setup_check.py`와 화면의 **설치 상태 확인**은 패키지 버전·프로젝트 경로·쓰기 권한·브라우저·SSL을 점검합니다.
계정 파일을 읽거나 브라우저·서버를 실행하거나 외부에 접속하지 않습니다.
브라우저 또는 온라인 SSL 환경이 준비되지 않아도 로컬 기능은 따로 안내합니다.
현재 검증용 Python의 LibreSSL 환경은 온라인 로그인 라이브러리의 지원 조건과 맞지 않아 안내가 표시됩니다.
실계정 공동 검증 전에 OpenSSL을 사용하는 Python 환경을 준비해야 합니다. [설치 점검 상세](docs/setup.md)

## 파일 비교

1. 인스타그램 공식 내보내기에서 **팔로워 및 팔로잉 / 전체 기간 / JSON**을 선택합니다.
2. 앱에서 한 번의 내보내기에 속한 ZIP 전체 또는 관련 JSON 전체를 선택하거나 끌어놓습니다.
3. **맞팔 안한 목록**을 누릅니다. `팔로잉 아이디 − 팔로워 아이디`를 중복 제거·정렬해 표시합니다.
4. 검색한 뒤 복사·저장 범위를 **검색 결과 / 전체 결과** 중 선택합니다. TXT는 한 줄에 아이디 하나,
   CSV는 UTF-8 BOM과 `username` 열을 사용합니다. 클립보드가 차단되면 직접 복사할 텍스트를 제공합니다.

`following.json`, `followers.json`, `followers_1.json`, `followers_2.json` 등의 분할 파일을 지원합니다.
파일 형식·번호·중복·손상 등을 검사하고 파일 목록과 인원수를 보여줍니다.
**마지막 분할 파일 누락, 전체 기간, 같은 계정 여부는 관계 JSON만으로 증명할 수 없어 미확인이라고 표시합니다.**
잘못된 파일은 이전 정상 자료를 덮어쓰지 않습니다.

**가져온 시각**은 로컬 처리 시각입니다. **내보내기 생성 시각**은 기본적으로 미확인이며,
알고 있을 때만 파일 선택 전에 입력할 수 있습니다. 입력한 시각에는 `직접 입력`이라고 표시합니다.
팔로우 기록의 날짜나 파일 저장 날짜를 생성 시각으로 추정하지 않습니다. 결과는 실시간 상태가 아닙니다.

CLI에서도 계정 ID 없이 가져올 수 있습니다. 이 명령은 서버나 계정에 접속하지 않습니다.

```sh
venv/bin/python import_export.py /path/to/export.zip
venv/bin/python import_export.py /path/to/following.json /path/to/followers_1.json
```

## 저장 자료와 복구

- `비교할 자료` 선택은 로그인·로그아웃과 별개로 저장됩니다. 로컬 자료는 `exports/local/`,
  계정 내보내기는 `exports/<숫자 ID>/`에 보관합니다. 세션·자료·로그는 Git에서 제외합니다.
- 오류별로 파일 가져오기, 다른 자료 선택, 계정 연결, 준비 확인, 기록 복구를 안내합니다.
  제출 전 중단된 준비만 다시 시작할 수 있습니다. 제출 여부가 불명확하거나 기록이 손상된 경우 새 내보내기를 자동 제출하지 않습니다.
- 손상된 기록은 복구 전에 보관합니다. 손상된 작업 기록을 복구하면 온라인 동작을 막고 로컬 기능을 안내합니다.
- **저장 자료 관리**에서 정리·삭제 범위와 용량을 먼저 확인하고 체크해야 삭제됩니다.
  미리보기 후 자료가 바뀌면 다시 확인해야 합니다. 정리는 현재 정상 자료를 유지합니다.
- 자료 삭제도 로그인 세션·내보내기 작업 기록·복구 기록·진행 중 다운로드는 유지합니다.
  이 기록들은 중복 제출 방지에 필요합니다. 로그아웃은 저장된 비교 자료를 삭제하지 않습니다.

## 선택 기능: 자동 내보내기

기존 로그인·인증 기능을 유지했습니다. 자동 내보내기는 공식 계정 센터의 화면을 처리하는 브라우저 자동화이며,
**실서비스 화면과 모바일 세션의 웹 호환성은 실제 계정으로 검증하지 않았습니다.**
대상을 확인하지 못하면 멈추고 직접 목록 수집으로 전환하지 않습니다. 프사·이름 조회와 언팔로우·차단 기능은 없습니다.

- **JSON 갱신**은 설정을 확인한 뒤 한 번 제출합니다. **JSON 준비 확인**은 기존 작업의 준비 상태를 확인하며 최소 30분 간격을 적용합니다.
- 준비 여부를 자동 반복 조회하지 않습니다. 앱 재시작이나 로컬 비교도 새 내보내기를 만들지 않습니다.
- 다운로드는 식별 정보로 이어받습니다. 분할 파일 식별이 불가능하면 화면 순서로 추측하지 않습니다.
  파일 묶음이 모두 저장되었다면 온라인 조회 없이 가져오기를 마칩니다.
- Google Chrome이 있으면 사용하고, 없으면 설치된 Playwright Chromium을 찾습니다.
  Chromium은 `venv/bin/python -m playwright install chromium`으로 설치합니다.
  이 자동화용 브라우저는 로컬 JSON 비교에는 필요하지 않습니다.

## 계정 없이 검증

```sh
venv/bin/python -m pip check
venv/bin/python -m pytest -q --ignore=test_browser_offline.py
RUN_OFFLINE_BROWSER_TESTS=1 venv/bin/python -m pytest -q test_browser_offline.py
```

Python 외부 연결을 차단하고 합성 자료만 사용합니다. 모의 브라우저도 모든 요청을 로컬로 대체하거나 차단하고 DNS를 막습니다.
설치 점검·앱 생성 테스트는 임시 프로젝트에서 수행하며 실제 계정 파일·사용자 앱·실행 중 서버를 사용하지 않습니다.
모의 화면 검증이 실제 계정 센터 호환성을 입증하는 것은 아닙니다.
