# Instagram Follow Management Tool

Instagram에서 **맞팔이 아닌 계정**을 확인하고 관리하기 위한 개인용 도구입니다.

Python과 FastAPI를 기반으로 제작했으며, 맞팔 여부를 분석하여 관리 대상 계정을 리스트로 확인할 수 있습니다.

## 주요 기능

* 맞팔이 아닌 계정 추적 및 리스트 조회
* 개별 계정 언팔로우
* 개별 계정 차단
* 여러 계정 일괄 언팔로우
* 여러 계정 일괄 차단

## 기술 스택

* Python
* FastAPI

## 사용 목적

개인 Instagram 계정의 팔로우 관계를 확인하고 정리하기 위한 목적으로 제작되었습니다.

## ⚠️ 주의사항

이 프로젝트는 **개인적인 용도로만 사용해야 합니다.**

Instagram의 자동화된 요청이나 대량 작업은 계정 제한, 기능 제한 또는 계정 잠금 등의 문제가 발생할 수 있습니다.

특히 벌크 차단 및 벌크 언팔로우와 같은 대량 작업을 사용할 경우 Instagram의 서비스 정책을 반드시 확인하시기 바랍니다.

본 프로젝트의 사용으로 인해 발생하는 계정 제한, 잠금, 데이터 손실 등의 문제에 대해서는 사용자가 책임을 부담합니다.
